# Data access and aggregate dictionary

Figure_5_data.csv contains one row per FDI tooth position. Fields: tooth_position, transitions (eligible positive-follow-up transitions), events (observed H→C outcomes), x and y (mean source coordinates), event_fraction (events/transitions). These are descriptive counts, not predicted risks. All 83 events occur in eight molar positions; absence of anterior events does not prove absence of risk.

Source Table_S1.xlsx is third-party participant-level material. The reproducible notebook downloads it from the source authors at a fixed commit and verifies SHA-256. It is omitted from this distributable package pending source reuse/redistribution verification. No individual predictions, IDs, contacts or clinical images are included.
